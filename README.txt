THE GREAT CONTINENT — LORE ENCYCLOPEDIA

This is a self-contained static wiki prototype.

HOW TO VIEW:
1. Extract the folder/ZIP.
2. Open index.html in a modern browser.
3. No server, framework, database, or installation is required.

The site contains:
- all current entries from the six supplied lorebooks
- 15 character pages
- character artwork supplied with the project
- search and category filters
- hash-based navigation
- human-readable character pages with Appearance, Personality, History, Life & Skills, Relationships, and Her Story

The technical bot fields (MBTI, speech guide, AI directives, etc.) are intentionally not shown on the public character pages.

The lorebook wording is kept as supplied; the site primarily changes presentation and navigation.
